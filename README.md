# Ganesh VIP Sports 🏎️👑

**Premium Exotic & Supercar Rentals • Pandharpur, Maharashtra**

A modern web application built for **Ganesh VIP Sports** featuring a curated exotic fleet, interactive technical car telemetry, custom VIP event packages, an interactive booking basket, and instant WhatsApp booking integration.

---

## 🌟 Key Features

- **🏎️ Elite Supercar Fleet Showcase**: Ferrari F8 Tributo, Lamborghini Huracán EVO, Ford Mustang GT 5.0, Porsche 911 Carrera S, BMW Z4 Roadster, and Mercedes-AMG G63 BiTurbo with category filters.
- **⚡ Interactive Telemetry & Specs**: Real-time comparison of horsepower, 0–100 km/h acceleration, top velocity, gearbox, and engine specs.
- **🛒 VIP Booking Basket & Drawer**: Add cars and amenities to calculate estimates and review bookings.
- **💬 2-Step WhatsApp Booking Confirmation**: Collects customer First Name, Last Name, and 10-digit mobile number before auto-generating a detailed booking message directly to **Ganesh Sawant (+91 8668811021)**.
- **👑 VIP Occasions**: Tailored packages for Grand Wedding Entries, Cinematic & Reel Shoots, VIP Celebrity Escorts, and Birthday Drives.
- **📱 Responsive Luxury UI**: Dark carbon supercar aesthetics, glassmorphism blur, Google Fonts (Outfit & Plus Jakarta Sans), and a sticky mobile action bar.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ganeshsawant8086-ux/Ganesh-vip-sports.git
   cd Ganesh-vip-sports
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
